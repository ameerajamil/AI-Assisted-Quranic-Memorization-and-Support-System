# User Stories

1. As a primary school student learning Quran by word, I want to view visual keyword cards containing the meaning of the words so that I can use the visual references to help me memorize the verses of the Quran.

2. As a primary school student, I want to view simple learning cues showing relationships between selected Quranic words and verses so that I can use these connections to support my memorization.
Linked requirements: FR2, FR3

3. As a parent of a primary school child learning Quran memorization, I would like my child to be able to access creative activities that are appropriate for memorization with verified Quran content so that I can support my child's memorization at home.
