# User Stories

1. As a primary school student learning Quran by word, I want to see visual keyword cards containing the meaning of the words so that I can use the visual references to help me memorize the verses of the Quran.
2. As a primary school student studying Quran memorization at primary school I want to get the words of the Quran in the proper order so that I can be able to recite it correctly.
3. As a parent of a primary school child learning Quran memorization, I would like my child to be able to access creative activities that are appropriate for memorization with verified Quran content so that I can support my child's memorization at home.
